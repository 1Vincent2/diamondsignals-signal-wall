# DiamondSignals Forensic Metric Language

## Core rule
Surface cards lead with cause-layer metrics. Legacy result/luck stats are secondary context only.

## Hitter surface language
- Avg EV -> Blast Path
- Barrel-like % -> Blast Rate
- Max EV -> Apex Damage
- Chase Rate -> SEAGER Score / Correct Aggression
- BABIP -> Surface Distortion / Luck Context only

## Pitcher surface language
- Whiff % -> Miss Engine
- FB Velo -> Velocity Fuel
- Extension -> Release Deception
- ERA / WHIP -> deprecated surface-result language
- IVB -> Carry Shape / IVB Proof
- IVB Delta -> Shape Gain
- VAA -> Attack Plane

## Product framing
The box score reports the outcome.
DiamondSignals detects the movement.
